# 插件开发指南

## 概述

Miss IDE 支持插件扩展机制，允许开发者通过插件扩展功能。本指南介绍如何开发和安装插件。

## 插件架构

```
┌─────────────────────────────────────────────────────────┐
│                     Miss IDE Core                       │
├─────────────────────────────────────────────────────────┤
│                   Plugin Manager                         │
│  ┌───────────────────────────────────────────────────┐ │
│  │           Plugin Registry (插件注册表)             │ │
│  └───────────────────────────────────────────────────┘ │
│         │                                               │
│  ┌──────▼──────┐  ┌──────▼──────┐  ┌──────▼──────┐     │
│  │  Built-in   │  │  External   │  │   Market    │     │
│  │   Plugin    │  │   Plugin    │  │   Plugin    │     │
│  └─────────────┘  └─────────────┘  └─────────────┘     │
└─────────────────────────────────────────────────────────┘
```

## 创建插件

### 1. 定义插件元数据

```dart
class MyPlugin implements MissPlugin {
  @override
  PluginMeta get meta => const PluginMeta(
    id: 'my-plugin',
    name: '我的插件',
    version: '1.0.0',
    description: '插件描述',
    author: '开发者名称',
    tags: ['custom', 'feature'],
    isBuiltIn: false,
  );
  
  @override
  List<String> get dependencies => [];
}
```

### 2. 实现核心方法

```dart
class MyPlugin implements MissPlugin {
  PluginState _state = PluginState.unloaded;
  
  @override
  PluginState get state => _state;
  
  @override
  Future<void> onInit() async {
    _state = PluginState.loading;
    // 初始化逻辑
    _state = PluginState.loaded;
  }
  
  @override
  Future<void> onDispose() async {
    _state = PluginState.unloaded;
  }
}
```

### 3. 贡献扩展点

#### 菜单扩展

```dart
@Override
List<MenuItem> contributeMenuItems() => [
  MenuItem(
    id: 'my-menu-item',
    label: '我的菜单',
    icon: Icons.extension,
    onTap: () => print('点击菜单'),
  ),
];
```

#### 命令扩展

```dart
@Override
List<Command> contributeCommands() => [
  Command(
    id: 'my.command',
    name: '我的命令',
    description: '执行自定义操作',
    shortcut: 'Ctrl+Shift+M',
    execute: () async {
      // 执行逻辑
    },
  ),
];
```

#### 面板扩展

```dart
@Override
Widget? contributePanel(String location) {
  if (location == 'toolbar:custom') {
    return MyCustomToolbar();
  }
  return null;
}
```

#### 设置项扩展

```dart
@Override
List<SettingsItem> contributeSettings() => [
  SettingsItem(
    key: 'my.setting',
    label: '我的设置',
    type: 'bool',
    defaultValue: true,
    description: '启用自定义功能',
  ),
];
```

## 插件生命周期

```
┌─────────┐    install()    ┌─────────┐    onInit()     ┌─────────┐
│ Unload  │ ──────────────▶ │ Loading │ ──────────────▶ │ Loaded  │
└─────────┘                 └─────────┘                 └─────────┘
     ▲                           │                           │
     │                           │ onDispose()              │
     │     uninstall()           │                           │
     └───────────────────────────┘                           │
                                                             │
     ┌─────────┐    enable()       ┌─────────┐               │
     │Disable  │ ───────────────▶ │ Loaded  │◀──────────────┘
     └─────────┘                  └─────────┘    disable()
```

## 安装插件

### 本地安装

```dart
final manager = PluginManager.instance;

// 安装插件
final result = await manager.installPlugin('my-plugin', {
  'enabled': true,
});

if (result.success) {
  print('插件安装成功');
} else {
  print('安装失败: ${result.error}');
}
```

### 启用/禁用

```dart
// 禁用插件
await manager.disablePlugin('my-plugin');

// 启用插件
await manager.enablePlugin('my-plugin');
```

### 卸载插件

```dart
await manager.uninstallPlugin('my-plugin');
```

## 内置插件

### ThemePlugin

主题插件，提供编辑器配色方案。

```dart
// 获取可用主题
final themes = themePlugin.availableThemes;

// 添加自定义主题
await themePlugin.addCustomTheme('my-theme', customColorScheme);
```

### LanguagePlugin

语言高亮插件，支持多种编程语言。

```dart
// 获取语言定义
final java = languagePlugin.getLanguage('java');

// 注册自定义语言
languagePlugin.registerLanguage(myLanguageDefinition);
```

### ToolPlugin

外部工具插件，集成反编译工具。

```dart
// 检查工具可用性
final jadxAvailable = toolPlugin.isToolAvailable('jadx');

// 获取可用工具
final tools = toolPlugin.availableTools;
```

## 插件市场

插件市场提供插件的浏览、安装和管理功能。

### 访问插件市场

```dart
// 在设置页面中访问插件市场
Navigator.push(
  context,
  MaterialPageRoute(
    builder: (context) => const PluginMarketPage(),
  ),
);
```

### 安装市场插件

```dart
// 从市场安装
final result = await pluginMarket.installFromMarket('plugin-id');

// 检查更新
await pluginMarket.checkForUpdates();
```

## 配置文件

插件配置存储在应用数据目录：

```
{app_data}/plugins/
├── manifest.json        # 插件清单
├── settings.json       # 插件设置
└── {plugin_id}/
    └── config.json     # 插件特定配置
```

## 安全考虑

1. **权限隔离**：插件运行在受限环境中
2. **代码签名**：市场插件需要签名验证
3. **权限控制**：敏感 API 需要用户授权

## 开发建议

1. **遵循规范**：使用标准扩展点
2. **错误处理**：做好异常捕获
3. **资源释放**：onDispose 中清理资源
4. **版本兼容**：考虑向后兼容
