# 云端同步配置指南

## 概述

Miss IDE Phase 4 支持云端同步功能，允许用户在不同设备间同步设置、项目和插件配置。

## 同步内容

### 设置同步

| 项目 | 说明 |

## 配置说明

### 初始化同步服务

```dart
import 'package:miss_ide/features/sync/domain/sync_service.dart';

final syncService = SyncService.instance;

// 配置同步服务
await syncService.initialize(token, const SyncConfig(
  enableSettingsSync: true,
  enableProjectSync: false,
  enablePluginSync: false,
  autoSync: true,
  syncIntervalMinutes: 5,
));
```

### 同步配置选项

```dart
class SyncConfig {
  /// 启用设置同步
  final bool enableSettingsSync;
  
  /// 启用项目同步
  final bool enableProjectSync;
  
  /// 启用插件同步
  final bool enablePluginSync;
  
  /// 自动同步
  final bool autoSync;
  
  /// 同步间隔（分钟）
  final int syncIntervalMinutes;
  
  /// 后端服务器地址
  final String? backendUrl;
  
  /// API 密钥
  final String? apiKey;
}
```

## 使用方式

### 手动同步

```dart
// 手动触发同步
final status = await syncService.syncAll();

switch (status) {
  case SyncStatus.success:
    print('同步成功');
    break;
  case SyncStatus.offline:
    print('设备离线');
    break;
  case SyncStatus.conflict:
    print('存在冲突');
    break;
  case SyncStatus.error:
    print('同步失败');
    break;
}
```

### 监听同步状态

```dart
// 监听状态变化
syncService.statusStream.listen((status) {
  print('同步状态: $status');
});

// 监听进度
syncService.progressStream.listen((progress) {
  print('同步进度: ${(progress * 100).toInt()}%');
});
```

### 处理冲突

```dart
// 监听冲突事件
syncService.conflictStream.listen((conflict) {
  // 显示冲突解决对话框
  showDialog(
    context: context,
    builder: (context) => ConflictResolutionDialog(
      conflict: conflict,
      onResolve: (resolution) {
        syncService.resolveConflict(
          conflict.id,
          resolution,
        );
      },
    ),
  );
});
```

## 冲突解决策略

### 自动策略

```dart
// 保留本地版本
await syncService.resolveConflict(
  conflictId,
  ConflictResolution.keepLocal,
);

// 保留远程版本
await syncService.resolveConflict(
  conflictId,
  ConflictResolution.keepRemote,
);

// 保留两个版本
await syncService.resolveConflict(
  conflictId,
  ConflictResolution.keepBoth,
);

// 手动解决
await syncService.resolveConflict(
  conflictId,
  ConflictResolution.manual,
);
```

### 冲突解决对话框

```dart
class ConflictResolutionDialog extends StatelessWidget {
  final SyncConflict conflict;
  final Function(ConflictResolution) onResolve;

  @override
  Widget build(BuildContext context) {
    return AlertDialog(
      title: Text('数据冲突 - ${conflict.name}'),
      content: Column(
        mainAxisSize: MainAxisSize.min,
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Text('本地版本: ${conflict.localValue}'),
          Text('远程版本: ${conflict.remoteValue}'),
        ],
      ),
      actions: [
        TextButton(
          onPressed: () => onResolve(ConflictResolution.keepLocal),
          child: const Text('使用本地版本'),
        ),
        TextButton(
          onPressed: () => onResolve(ConflictResolution.keepRemote),
          child: const Text('使用远程版本'),
        ),
        FilledButton(
          onPressed: () => onResolve(ConflictResolution.manual),
          child: const Text('手动选择'),
        ),
      ],
    );
  }
}
```

## 离线支持

### 离线队列

当设备离线时，更改会自动加入离线队列：

```dart
// 添加到离线队列
syncService.addToOfflineQueue({
  'type': 'settings',
  'action': 'update',
  'data': {...},
});

// 恢复网络后自动同步
// 离线队列会自动处理
```

### 同步状态查询

```dart
final status = await syncService.getSyncStatus();

print('状态: ${status['status']}');
print('上次同步: ${status['lastSyncTime']}');
print('待同步项: ${status['pendingChanges']}');
```

## 后端配置

### 支持的后端

1. **Firebase**
   ```yaml
   backend_url: https://miss-ide.firebaseio.com
   api_key: your-firebase-api-key
   ```

2. **Supabase**
   ```yaml
   backend_url: https://your-project.supabase.co
   api_key: your-supabase-api-key
   ```

3. **自建服务**
   ```yaml
   backend_url: https://api.your-server.com
   api_key: your-api-key
   ```

### API 接口

```
POST   /api/sync/settings       # 同步设置
POST   /api/sync/projects       # 同步项目
POST   /api/sync/plugins        # 同步插件
GET    /api/sync/status         # 获取同步状态
POST   /api/sync/resolve        # 解决冲突
```

## 数据安全

### 传输加密

- 所有数据传输使用 HTTPS
- 使用 TLS 1.3 加密

### 存储加密

- 敏感数据在本地使用 AES 加密
- 服务器端使用行业标准加密

### 隐私保护

- 最小化数据收集
- 用户数据隔离存储
- 支持数据删除请求

## 故障排除

### 同步失败

1. 检查网络连接
2. 确认登录状态
3. 查看同步日志
4. 重试同步

### 数据丢失

1. 检查离线队列
2. 从备份恢复
3. 联系技术支持

### 冲突过多

1. 减少同步间隔
2. 手动解决冲突
3. 考虑使用合并策略

## 最佳实践

1. **定期同步**：保持数据最新
2. **重要备份**：定期本地备份
3. **冲突记录**：保留冲突历史
4. **网络优先**：优先使用稳定网络
