# 外部工具使用说明

## 概述

Miss IDE 支持集成多种外部 Android 逆向工具，提供无缝的协作体验。本文档介绍如何配置和使用这些外部工具。

## 支持的工具

### 1. MT Manager

**功能**：强大的 APK 反编译、编辑和签名工具

**包名**：`bin.mt.plus`

**支持的操作**：
- 📁 文件浏览与管理
- 📦 APK 反编译
- ✏️ DEX/Smali 编辑
- 🔐 APK 签名

**安装方式**：
- [酷安市场下载](https://coolapk.com/apk/bin.mt.plus)
- [官方渠道](https://mt2.cn)

### 2. APK Editor Pro

**功能**：可视化 APK 资源编辑工具

**包名**：`com.mod.apt`

**支持的操作**：
- 🖼️ 图片资源替换
- 📝 字符串资源编辑
- 📐 XML 布局编辑
- 🔧 DEX 字节码修改

**安装方式**：
- [酷安市场下载](https://coolapk.com/apk/com.mod.apt)

### 3. Termux

**功能**：Android 终端模拟器，支持命令行操作

**包名**：`com.termux`

**支持的操作**：
- 💻 执行 shell 命令
- 📜 运行脚本文件
- 🔌 SSH 连接
- 📂 高级文件操作

**安装方式**：
- [F-Droid 下载](https://f-droid.org/packages/com.termux)（推荐）
- [GitHub 发布页](https://github.com/termux/termux-app/releases)

### 4. Shizuku

**功能**：无需 Root 权限提升工具

**包名**：`rikka.shizuku`

**支持的操作**：
- 🔓 以 Root 权限执行命令
- 📁 访问受保护的文件
- 🛠️ 系统级文件操作
- 🔧 高级 APK 操作

**安装方式**：
- [Google Play](https://play.google.com/store/apps/details?id=rikka.shizuku)
- [GitHub 发布页](https://github.com/RikkaApps/Shizuku/releases)

**使用前提**：
- 需要通过 ADB 启动 Shizuku
- 首次使用需要授权

### 5. ZArchiver

**功能**：压缩/解压工具

**包名**：`zdevs.archiver`

**支持的操作**：
- 📦 压缩文件
- 📂 解压归档
- 👁️ 查看归档内容

**安装方式**：
- [Google Play](https://play.google.com/store/apps/details?id=zdevs.archiver)

## 使用指南

### 检测工具安装状态

```dart
import 'package:miss_ide/engine/external_tools/external_tool_service.dart';

final service = ExternalToolService.instance;

// 检测单个工具
final mtInfo = await service.checkToolInstalled(ExternalToolType.mtManager);
if (mtInfo.isInstalled) {
  print('MT Manager 版本: ${mtInfo.version}');
} else {
  print('MT Manager 未安装');
}

// 批量检测所有工具
final allTools = await service.checkAllToolsInstalled();
for (final tool in allTools) {
  print('${tool.name}: ${tool.isInstalled ? "已安装" : "未安装"}');
}
```

### 启动外部工具

```dart
// 使用 MT Manager 打开 APK
final result = await service.openWithMT('/sdcard/apps/MyApp.apk');
if (result.success) {
  print('已在 MT Manager 中打开');
} else {
  print('打开失败: ${result.error}');
}

// 使用 APK Editor 打开
await service.openWithAPKEditor('/sdcard/apps/MyApp.apk');
```

### 执行 Termux 命令

```dart
// 执行单个命令
final output = await service.executeInTermux('ls -la /sdcard');
print(output);

// 执行脚本
await service.executeInTermux('bash /sdcard/scripts/my_script.sh');
```

### Shizuku 集成

```dart
// 检查 Shizuku 状态
final status = await service.checkShizukuStatus();

switch (status) {
  case ShizukuStatus.notInstalled:
    print('请安装 Shizuku');
    // 引导用户安装
    await service.openMarketPage(ExternalToolType.shizuku);
    break;
    
  case ShizukuStatus.notRunning:
    print('请启动 Shizuku');
    break;
    
  case ShizukuStatus.requesting:
    print('正在请求权限...');
    break;
    
  case ShizukuStatus.authorized:
    print('Shizuku 已授权，可以执行高级操作');
    break;
    
  case ShizukuStatus.denied:
    print('权限被拒绝');
    break;
}

// 请求 Shizuku 权限
await service.requestShizukuPermission();

// 使用 Shizuku 执行命令
final result = await service.executeWithShizuku('ls -la /data/app');
print(result);

// Shizuku 文件操作
await service.shizukuMkdir('/data/local/tmp/my_app');
await service.shizukuCopy('/sdcard/file.apk', '/data/local/tmp/file.apk');
await service.shizukuDelete('/data/local/tmp/temp');
```

### 下载安装工具

```dart
// 打开应用市场下载页面
await service.openMarketPage(ExternalToolType.mtManager);
await service.openMarketPage(ExternalToolType.termux);
```

## Android 11+ 适配

### 问题说明

Android 11 (API 30) 引入了包可见性限制，应用无法直接查询和启动未声明的第三方应用。

### Miss IDE 的适配方案

1. **queries 声明**：在 AndroidManifest.xml 中声明所有支持的外部工具包名
2. **动态可见性检测**：使用 `isPackageVisible()` 检测工具是否可见
3. **安装引导**：自动引导用户安装缺失的工具

### 所需声明

```xml
<!-- AndroidManifest.xml -->
<queries>
    <!-- MT Manager -->
    <package android:name="bin.mt.plus" />
    
    <!-- APK Editor -->
    <package android:name="com.mod.apt" />
    
    <!-- Termux -->
    <package android:name="com.termux" />
    
    <!-- Shizuku -->
    <package android:name="rikka.shizuku" />
    <package android:name="rikka.shizuku.permission.provider" />
    
    <!-- ZArchiver -->
    <package android:name="zdevs.archiver" />
    
    <!-- 应用市场 -->
    <intent>
        <action android:name="android.intent.action.VIEW" />
        <category android:name="android.intent.category.BROWSABLE" />
        <data android:scheme="market" />
    </intent>
</queries>
```

## 错误处理

### 常见错误

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| `TOOL_NOT_INSTALLED` | 工具未安装 | 引导用户下载安装 |
| `PACKAGE_NOT_VISIBLE` | 包不可见 (Android 11+) | 检查 queries 声明 |
| `LAUNCH_FAILED` | 启动失败 | 检查 Intent 配置 |
| `SHIZUKU_NOT_AUTHORIZED` | Shizuku 未授权 | 请求用户授权 |

### 处理示例

```dart
Future<void> safeLaunch(ExternalToolType type, String filePath) async {
  final service = ExternalToolService.instance;
  
  // 1. 检测安装状态
  final toolInfo = await service.checkToolInstalled(type);
  
  if (!toolInfo.isInstalled) {
    // 2. 引导安装
    final confirm = await showDialog<bool>(
      context: context,
      builder: (context) => AlertDialog(
        title: Text('${toolInfo.name} 未安装'),
        content: Text('是否前往下载 ${toolInfo.name}？'),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(context, false),
            child: const Text('取消'),
          ),
          ElevatedButton(
            onPressed: () => Navigator.pop(context, true),
            child: const Text('下载'),
          ),
        ],
      ),
    );
    
    if (confirm == true) {
      await service.openMarketPage(type);
    }
    return;
  }
  
  // 3. 启动工具
  final result = await service.launchTool(type, filePath: filePath);
  
  if (!result.success) {
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(
        content: Text('启动失败: ${result.error}'),
        action: SnackBarAction(
          label: '设置',
          onPressed: () => service.openAppSettings(toolInfo.packageName),
        ),
      ),
    );
  }
}
```

## 性能优化

### 1. 延迟检测

```dart
// 不要在应用启动时检测所有工具
// 而是按需检测

class LazyToolChecker {
  final _cache = <ExternalToolType, ExternalToolInfo?>{};
  
  Future<ExternalToolInfo> getTool(ExternalToolType type) async {
    if (!_cache.containsKey(type)) {
      _cache[type] = await ExternalToolService.instance
          .checkToolInstalled(type);
    }
    return _cache[type]!;
  }
}
```

### 2. 并行检测

```dart
// 同时检测多个工具
final results = await Future.wait([
  service.checkToolInstalled(ExternalToolType.mtManager),
  service.checkToolInstalled(ExternalToolType.apkEditor),
  service.checkToolInstalled(ExternalToolType.termux),
]);
```

## 安全考虑

### 1. Intent 安全性

- 只发送必要的 Intent 数据
- 避免传递敏感路径信息
- 使用 Content URI 代替文件路径

### 2. Shizuku 权限

- 仅在必要时请求 Shizuku 权限
- 明确告知用户权限用途
- 提供权限撤销选项

### 3. 数据隔离

- 不缓存敏感的外部工具返回结果
- 及时清理临时文件
